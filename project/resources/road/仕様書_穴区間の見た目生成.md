# 仕様書: 穴区間(赤レール)の見た目生成

Claude Code にこのファイルを渡して実装する想定の仕様書。
検証画像: hole_demo.png (穴2.4m + 警告帯1m + road_endキャップ、Python検証済み)

## 0. 前提 (現状の実装)

- SplineRail から FrameCache 経由で道メッシュを生成する RoadMeshBuilder が動作中
- レールエディタにはノード単位の「穴」フラグが既にある (落下区間、ジャンプで飛び越え可)
- 落下のゲームプレイ判定は既存。**本仕様は見た目(メッシュ)のみ**
- 専用モデルは作らない。生成 + 既存アセット(road_end)で完結する

## 1. データ仕様

### 1-1. 穴区間の取得API (SplineRail に追加)
```
struct HoleInterval { float d0, d1; };            // レール距離[m]
std::vector<HoleInterval> GetHoleIntervals() const;
```
- ノードの「穴」フラグから距離区間へ変換する
  (フラグが立った連続ノード列 → [最初のノード距離, 最後のノード距離] を1区間に)
- 区間はソート済み・重なりなしで返す
- **落下判定も同じこの区間を参照するようにリファクタ**(見た目と挙動のズレ防止)。
  既存の判定ロジックが別形式なら、判定側をこのAPIに寄せる

## 2. 生成仕様 (RoadMeshBuilder の変更)

### 2-1. 穴を開ける
- リングを置く際、その距離 d が いずれかの HoleInterval 内なら **リングを出さない**
  (リボンが区間の前後で2本に分かれる)
- 区間の境界にはちょうど d = d0 / d1 のリングを必ず置く
  (適応サンプリングの出力に境界距離を強制挿入する)

### 2-2. 両端のキャップ
- 各穴の両端に road_end モデルを自動配置する (レール終端の配置ロジックT4を流用)
  - 手前側 (d0): forward = +tangent (開口が道側を向く)
  - 奥側 (d1): forward = -tangent (up軸まわり180°回転)
  - 位置・向きは FrameCache の GetFrameAtDistance(d0/d1) から取る
- キャップの開口断面は道の断面と同一なので継ぎ目は出ない

### 2-3. 警告帯 (危険テクスチャ)
- 穴の手前後 1.0m (調整項目化: warnLength) の上面2頂点の v を危険帯に切替:
```
通常上面: v = 0.7500 (左) / 1.0000 (右)
危険帯  : v = 0.2070 (左) / 0.2734 (右)     // アトラスv5で追加
判定    : d ∈ [d0 - warnLength, d0) または (d1, d1 + warnLength]
```
- 切替の境目は坂と同様「同位置の二重リング」で帯の混ざりを防ぐ
- u はいつも通り d / 2.0。危険帯は全幅描画なのでREPEATが効く

## 3. アセット (同梱済み・差し替えのみ)

- road_atlas.png を v5 に差し替え
  - **既存のエンジン参照値 (上面/側面/ベベル/底/坂帯のv) は一切変更なし**
  - 追加: 危険帯 v = 0.2070〜0.2734 (赤地 + クリーム45°ストライプ)
  - モデル用領域を再配置したため、全GLB (straight/corner/t/cross/end/skinned) も
    同梱のv5版に差し替えること (旧GLBと旧アトラスの組合せはUVがズレる)

## 4. 受け入れ条件

- [ ] 穴フラグを付けた区間で道メッシュが途切れ、両端が road_end で丸く閉じる
- [ ] 穴の手前後 1.0m の上面が赤ストライプになる (中央破線は消える)
- [ ] カーブ上・坂上の穴でも破綻しない (境界リング強制挿入が効いていること)
- [ ] 穴区間とプレイヤーの落下判定区間が完全に一致する (GetHoleIntervals共通参照)
- [ ] ノードの穴フラグ編集で該当レールの道だけ再生成される
- [ ] ドローコール増加は穴1個につき road_end 2個ぶんのみ

## 5. テスト手順

1. 直線レールに穴1区間 → 隙間+キャップ+警告帯を目視確認
2. カーブ途中に穴 → キャップの向きが接線に沿うこと
3. 穴を2区間連続で配置 → 区間ごとに独立して開くこと
4. Playで穴に進入 → 落下位置と見た目の隙間が一致すること
5. パフォーマンスモニターでドローコール増加数を確認

## 6. Claude Code への投げ方 (プロンプト例)

```

警告帯UV/road_end配置) です。コードの書き方は提案ベースで進めて、
各ステップで私が確認します。まず §1-1 のAPIから。
受け入れ条件 §4 を満たしたら完了です。
```
