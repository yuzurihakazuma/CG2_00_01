# 道メッシュ v3 (カーブ追加版)

## v2からの追加
- road_corner.glb/.obj : 90°カーブ (64三角形)
  - 2×2mタイル、開口 = +X と +Y、回転中心 = タイル角(+1,+1)
  - 90°回転で4方向のカーブに対応 (0°=右下から上/右, 90°, 180°, 270°)
  - 両開口とも標準断面と数値検証で完全一致
  - 上面には円弧に沿った破線入り (アトラス更新済み)
- GUIDE_スプライン道生成.md : レール自由曲線に完全追従する
  エンジン内メッシュ生成の実装手順書 (こちらが本命、詳細はガイド参照)

## 使い分け
- グリッドで組むエリア (交差点・分岐・広場) → モデルピース
- SplineRailに沿う道 → ガイドの生成方式 (同じアトラスを使うので見た目が揃う)
