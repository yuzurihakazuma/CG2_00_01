# クラフト風 道メッシュ (レール下の地面用)

## ファイル
- road_segment.glb / .obj : タイル式セグメント (幅4 × 長さ4 × 厚み1)
- road_end.glb / .obj     : 終端キャップ (接続面はセグメントと同一断面)
- road_paper_green.png    : 上面テクスチャ (緑の紙 + 端の白ステッチ)
- road_cardboard.png      : 側面/底テクスチャ (段ボール + 中芯の縦じま)

## 座標系
- OBJ: X=幅, Y=進行方向, Z=上 (Z-up)
- GLB: glTF標準の Y-up に変換済み (Blenderで開くと自動で正しく立つ)

## エンジンでの使い方 (想定)
1. SplineRail に沿って長さ4ごとに road_segment を配置 (Y+方向へ連結)
2. 断面が同一なので、位置を 4.0 の倍数で並べるだけで継ぎ目が一致する
3. 道が終わる位置では最後のセグメントを road_end に差し替える
   (接続面は y=0 側。向きに注意)
4. テクスチャU座標は長さ方向に流してあるため、連結してもテクスチャが連続する

## 注意
- セグメントの両端は開いている (フタ無し)。単体で置くと端の断面が見えるので、
  必ず連結するか終端キャップで閉じること
- 法線は全て外向きで検証済み (バックフェースカリング対応)
