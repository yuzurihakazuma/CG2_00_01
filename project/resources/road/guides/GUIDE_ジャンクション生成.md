# ジャンクション生成ガイド (任意角度の曲がり角・T字・十字を接続する)

検証画像: junction_2way.png (溶接コーナー115°) / junction_3way.png (T字 0/100/220°) /
junction_4way.png (斜め十字 0/80/190/280°)
検証結果: 3構成すべてで道とパッチの入口の継ぎ目誤差 = 0 (浮動小数点誤差のみ)

## 考え方

共有ノード(レール同士がつながる点)ごとに「ジャンクションパッチ」を1個生成する。
- 各道はノードの **t_cut 手前で止める** (いつもの開放断面のまま)
- 隙間をパッチ (上面の扇 + ベベル + 壁 + 底) で埋める
- パッチの入口断面は道の断面と定義から一致する → 継ぎ目ゼロ
- 2本(曲がり角)・3本(T)・4本(十字)・何度の角度でも **同じコード** で処理できる

## 手順

### 1. ジャンクションの検出
レールのつながりからノードごとに「そこから出ていく方向」のリストを作る:
- 端点同士の溶接ノード → 方向2本
- 端点を他レールの途中へ連結したノード → 本線が2本 + 支線1本 = 方向3本
- 方向は接線を水平に射影して正規化。角度でソートしておく

### 2. カット距離 t_cut の計算
隣り合う方向ペア(ウェッジ)ごとに、間の角度 φ で分類:
```
φ < 175°  : マイター。左右の道の縁線(半幅Wオフセット)の交点までの距離 tm を計算
             → 両方の道の t_cut 候補 = tm + 0.15
175〜185° : ほぼ直進。何もしない
φ > 185°  : 外周を円弧にする(後述)。t_cut への影響なし
```
各道の t_cut = 候補の最大値 (最低 0.35)。
縁線の交点は2Dの直線交差:`N + t*(d_i) + W*left_i = N + s*(d_j) - W*left_j` を解くだけ。

### 3. 道側の変更 (1行レベル)
RoadMeshBuilder のサンプリング範囲を「0〜全長」から
「t_cut(始点側ノード) 〜 全長 - t_cut(終点側ノード)」に変える。それだけ。

### 4. パッチの生成
ウェッジ(i→j)ごとに境界点列を作る (幅wで関数化して2回使う):
```
boundary(i, w):
  a = N + t_cut_i * d_i + w * left_i        // 道iの左端
  b = N + t_cut_j * d_j - w * left_j        // 道jの右端
  マイター: [a, 縁線交点C, b]
  直進    : [a, b]
  円弧    : aからbへNを中心に12°刻みで回る点列 (半径は端点間で線形補間)
```
- **上面**: 内側境界 boundary(i, W-B) と各道の入口上端(±(W-B))をつないだ
  ループを、ノード中心(高さT)から扇状に三角形分割
- **ベベル**: boundary(W-B)(高さT) と boundary(W)(高さT-BH) の間にクアッド
- **壁**: boundary(W) を高さ 0〜T-BH に押し出し
- **底**: boundary(W) + 入口下端のループを、ノード(高さ0)から扇分割
- 入口部分にはベベル・壁を張らない (道の断面がそのまま入る)

### 5. UV
- 上面: アトラスの無地グリーン帯へ平面マッピング
  `u = (x-Nx)/2 を wrap` / `v = 0.89 + ((y-Ny)/2 mod 1) * 0.09`
  (中央破線は入口で自然に途切れる。実際の交差点も線は途切れるので違和感なし)
- ベベル/壁/底: 境界に沿った累積距離を u に、v はいつもの帯の値

## 制約と運用ルール

- **ジャンクション付近は平坦にする**: 方向を水平射影しているので、共有ノードの
  前後1.5mくらいはレールの高さを揃える(レール編集側の運用ルール)
- 2本溶接で角度が浅い(150°以上=ゆるいカーブ)場合は、パッチより
  「2本を1本のパスとして連続生成」の方が滑らかで綺麗。
  パッチは鋭い曲がり角と3本以上用と使い分けるとベスト
- 再生成はノード編集時のみ: 該当パッチ + 隣接する道の端だけ作り直す
- コスト: パッチ1個 180〜250三角形 (実測)。実行時コストはゼロ

## すぐ動かしたい場合の暫定案 (コード追加ゼロ)
ジャンクションのノードを2mグリッドに置き、進入方向を90°に整えて
road_t / road_cross タイルを置く。制約はきついが今日から見た目は直る。
本命は上のパッチ生成。

## 実装順
1. ジャンクション検出 + t_cut計算 + 道を手前で止める (この時点で重なりは消える)
2. パッチの上面+底だけ生成 (穴が埋まる)
3. ベベル+壁を追加 (完成)
